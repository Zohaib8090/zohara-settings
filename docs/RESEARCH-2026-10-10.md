# Research done 2026-10-10 (summaries; sources were read by sub-agents, some only from reviews)

Marked **[S]** = read in source or an official page, **[R]** = reviews/forums only, **[M]** = from memory. Treat [R]/[M] as leads.

## Zorin's desktop cube [S for the upstream extension]
Zorin's cube is a branded version of the GNOME extension **Schneegans/Desktop-Cube** (GPL-3; `extension.js`, `src/DragGesture.js`). Zorin's own fork was not found
publicly. From the source: an N-sided prism; with `last-first-gap` (default) the faces cover half a circle (`180/(N-1)`, 90 for N=2) so there is no wrap-around;
camera fov 60; the cube is pulled back while turning; windows float in front of the faces (parallax 0.5); vertical drag tilts up to 50 degrees; no reflections;
3 finger horizontal swipe, live, on release a slow swipe snaps and a fast one flings (velocity thresholds, deceleration 0.997). Zorin 17 added it as "Spatial
Desktop" in Zorin Appearance > Effects, off by default. We used its numbers, not its code.

## Building it for KWin [S]
KWin core reads 3/4 finger swipes and feeds desktop-switch effects; QML effects cannot see that progress but can register their own `SwipeGestureHandler`
(`progress` 0..1, `activated` on lift, `cancelled`). The official KDE cube (`kdeplasma-addons`, Quick3D) is an on-demand overview only. `marhensa/kwin-effects-prism`
rotates a prism after a switch (no live finger following). A C++ plugin would have to be rebuilt for every KWin minor version; the QML-only effect was chosen.

## Zorin OS Pro [S zorin.com/os/pro and Zorin blog posts]
12 layouts (8 Pro-only: macOS-like, Windows 11-like, Windows Classic-like, ChromeOS-like, Compact, Ubuntu-like, elementary-like, Mint-like; Core has Windows-like,
Touch, Windows List-like, GNOME Shell-like), switched in Zorin Appearance. About 29 creative/productivity apps, 15 wallpapers, install support, one-time
payment per major version (about $47.99 [R]). Zorin Connect, Windows app support (Wine) and web apps are in Core. Gestures on by default and not configurable
(3 finger up overview, 3 finger left/right workspaces, pinch zoom). What a layout changes under the hood is undocumented.

## Other distros [R, vendor pages often unreachable]
Feren OS: layouts inside global themes with a choice of which parts to apply. Deepin: dock modes Fashion (floating) and Efficient (full width), position/size/hide.
COSMIC: export/import of the whole appearance. Plasma 6.6: "save the current look as a global theme" (restore bugs reported). Garuda/CachyOS: performance toggles in
an app (complaints: no tooltips, a checkbox that did not stop the service). Bazzite: one "Portal" hub after install. Latte Dock is dead on Plasma 6. Not covered:
elementary, Kubuntu, openSUSE, Fedora GNOME Tweaks, EndeavourOS.

## Windows tweak tools [S for Winhance and WinUtil]
WinUtil (ChrisTitusTech, PowerShell+WPF, JSON config): tabs Install/Tweaks/Config/Updates/Win11ISO; 67 tweaks in Essential, Advanced (marked caution),
Customize Preferences (about 28 switches), Performance Plans; presets Minimal (4) / Standard (12) / Advanced (17); each tweak stores its original value so
Undo and Restore Defaults work, plus a restore point. Winhance (memstechtips, C# WinUI 3, PolyForm Shield licence): pages for software, Optimize (privacy,
gaming and performance, power, updates, sound, notifications) and Customize; `IsRecommended` markers, inline warnings, export/import of a config file.
What makes them popular: a flat searchable list of plain-language switches, a separate "caution" zone, presets, undo with stored original values, export/import.
Linux equivalents for a Zohara "Performance & privacy" page [M]: KDE feedback off (`PlasmaUserFeedback`), geoclue masked, crash reports, zram, sysctl,
CPU governor via power-profiles-daemon, I/O scheduler udev rule, boot services (`NetworkManager-wait-online`), journal size, Baloo, gamemode,
`vm.max_map_count`, autostart entries, a debloat checklist with a `pacman -Rns --print` preview, update policy (never a partial upgrade on Arch).

## Netflix, Widevine and HDR [M]
Desktop Linux browsers only get Widevine **L3** (software), so Netflix is limited to about 720p in the browser and has no 4K or HDR; L1 needs a hardware-protected
video path that Google gives only to ChromeOS/Android. Windows gets up to 1080p/4K through PlayReady in the Netflix app or Edge. Plasma 6.7 supports HDR on
Wayland but needs a display that reports it: the owner's panel says `HDR: incapable`, no VRR, no wide gamut.

## Suggested build order (the assistant's recommendation, accepted in spirit)
1. Make what exists trustworthy (the owner tries alpha). 2. Layout presets with a built-in undo (snapshot before apply). 3. The cube (done) and its polish.
4. Performance & privacy page with presets and a caution group, reusing the undo mechanism. 5. First-run welcome that asks for a layout. 6. Later: 3D window
switcher, accent colours, tiling, per-device equalizer, app bundles.
